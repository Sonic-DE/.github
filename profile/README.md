## SonicDE, the Sonic Desktop Environment

SonicDE is the community-driven desktop environment forked from KDE Plasma 6. It aims to preserve and improve X11 support and init-system independence, making it a complete and viable alternative. We currently maintain 145 components, including the customized `sonic-win` window manager and compositor, Sonic Workspace components, the Silver theme, the Sonic Login Manager, and supporting libraries.
